# M-Control Web

واجهة ويب عربية أولية قابلة للنشر كصفحة ثابتة.

## النشر كرابط عام
1. أنشئ مستودعًا جديدًا في GitHub.
2. ارفع `index.html` و`manifest.webmanifest` و`sw.js` إلى جذر المستودع.
3. من Settings ثم Pages اختر Deploy from a branch، وحدد الفرع `main` والمجلد `/root`.
4. سيظهر رابط ثابت على نطاق `github.io`. يمكن إضافة نطاق مخصص لاحقًا.

## بخصوص "للأبد"
لا توجد استضافة أو رابط يمكن ضمان بقائه إلى الأبد؛ استمرار الرابط يعتمد على بقاء حساب الاستضافة والخدمة. يمكن إبقاء الموقع متاحًا مجانًا مدة طويلة باستخدام GitHub Pages، مع الاحتفاظ بنسخة احتياطية من الملفات.

## حدود النسخة
هذه واجهة تجريبية فقط: رمز الربط لا ينشئ اتصالًا حقيقيًا بين جهازين، واختيار الملفات محلي ولا يرفعها. لا يوجد تحكم عن بعد أو تسجيل صوت أو قراءة رسائل. يلزم خادم وإجراءات أمان وموافقة ظاهرة قبل بناء ميزات اتصال حقيقية.
